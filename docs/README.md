# 기획 문서 안내

MonBTI의 기획서는 이 폴더 하위에 Markdown으로 관리합니다.

| 문서 | 역할 |
| --- | --- |
| [project-plan.md](project-plan.md) | 최신 제품 기획과 사용자 흐름 |
| [test-design.md](test-design.md) | 검사·분류·추천 설계 |
| [data-schema.md](data-schema.md) | 원본 시트, 입력 규격과 사이트 참조 방법 |
| [decisions.md](decisions.md) | 날짜별 확정 사항과 방향 변경 |
| [references.md](references.md) | 참고 자료의 제목과 링크 목록 |
| [development.md](development.md) | 개발 상태, 실행 방법, AI 협업 |

## 관리 원칙

- 확정된 요구사항과 검토 중인 제안을 구분합니다.
- 대화에서 정리한 내용은 사용자가 저장소 반영을 명시적으로 요청했을 때만 기록합니다.
- 반영을 요청받은 방향 변경은 최신 기획서와 [루트 README](../README.md)에 함께 수정합니다.
- 변경 이유와 과거 방향은 결정 기록에 남깁니다.
- 참고 자료가 추가되면 README 하단과 참고 자료 문서를 함께 수정합니다. 제목과 링크만 있는 단순한 목록을 사용합니다.
- 문서가 늘어나면 주제별 파일을 추가하고 이 목록에 연결합니다.
- 한국어로 작성하고, 파일명은 의미를 알 수 있는 소문자 영문과 하이픈을 사용합니다.
