## 자료별 검토 기록에 포함할 항목

- 자료 ID, 원문 URL, 확인한 제목·제작자·게시일
- 검토일과 확인한 범위: 본문, 자막, 이미지, 댓글 등
- 대상 작품과 업데이트 시점
- 분류 기준, 무기별 설명, 질문으로 전환할 수 있는 아이디어
- 영상 타임스탬프 또는 이미지·본문 위치
- 와일즈에 적용 가능 여부와 별도 확인이 필요한 내용
- 채택·수정·보류한 부분과 이유
- 반영한 기획 문서, 질문·결과 ID

자료를 읽지 못하면 접근 제한이나 필요한 자료를 기록하고 검토 대기 상태를 유지합니다.
새 자료는 이 문서와 README의 마지막 참고 자료 섹션에 함께 등록합니다.
